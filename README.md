# WhaleFlow 0.4.0 · 本地脚本、分镜与三维导演舞台

Windows 本地 React / React Flow 创作画布，使用用户配置的 OpenAI 兼容服务或 Ollama。本次 rebuild 0.4 加入脚本与分镜编辑、真实模型草案任务、分镜图/参考图编辑/首帧视频任务，以及独立 WebGL1 导演舞台。它是独立实现，不是原站 wrapper、官方客户端或源码恢复，不承诺原站功能或效果一致。

本轮正式前端构建、全量 Node 178 项、真实隔离 Chrome 15 组交互断言，以及原生 9 项画布 + 8 项模型设置检查已通过。浏览器覆盖创作编辑、真实 WorkflowEngine 受控协议、WebGL 像素与截图恢复；真实供应商生成未验收。发行包逐条摘要与解压运行结果以随包 verification 和包外 SHA256SUMS 为准。旧版测试数量与截图不作为本版通过依据，见[验证记录](<VALIDATION.md>)。

桌面运行需要 Windows x64、.NET Framework 4.8 和系统 Microsoft Edge WebView2 Runtime。完整程序包须解压到新的可写目录后运行，保留 EXE、DLL、host、native-shell、lib、dist 和许可文件；不能只复制 EXE 或在 ZIP 中直接运行。最终发行路径与摘要以本轮实际生成的归档和验证报告为准，当前文档不表示已经完成打包或桌面安装。

本版源码位于独立的 whaleflow-v4 目录。旧版工程、程序、快捷方式和个人 Data 不读取迁移、不覆盖；共享依赖/vendor junction 只读，不安装或替换依赖。回退时退出本版，运行原快捷方式并使用原 Data 与旧项目备份。新版项目请另存副本，不覆盖旧备份。

## 脚本与分镜工作台

从脚本/分镜节点进入工作台，编辑作品名称、梗概、视觉风格、画幅、完整脚本，以及角色、场景、道具描述。分镜条目包含画面描述、时长、景别、机位、对白、声音、生成提示词和可选参考图。保存使用文档 revision 比较；外部修订冲突会报错，避免无提示覆盖。关闭未保存编辑需要确认。

建议按以下顺序使用：

1. 先填写脚本和资产描述。使用本地拆分可按非空行生成分镜草案；这是确定性文本拆分，不是 AI 理解。提示词模板也是本地拼接，不调用模型。
2. 要使用真实模型拆分，先在模型服务设置中配置文本角色模型，再提交模型草案任务。程序在画布新增普通文本任务，通过现有工作流运行。任务成功后回到工作台读取模型草案；输出必须符合严格 JSON 结构，并匹配发起时的文档修订。
3. 检查草案后显式应用，再保存。草案不会自动覆盖正式分镜；脚本修订变化后，过期模型草案需要重新生成。DEMO 文本用于离线演示，不代表真实模型拆分，也不保证能作为有效分镜 JSON 应用。
4. 编辑镜头提示词，选择需要的镜头及图片模型，生成分镜图。任务成为普通画布节点，可以查看状态、结果和错误。没有选中镜头时会使用全部镜头。
5. 在镜头中选择参考图后，图片任务使用真实图像编辑接口；视频任务使用参考图作为首帧输入。未显式指定参考图的视频任务会查找同一镜头、同一文档修订的成功分镜图；缺失时要求先生成图片或选择参考图。

分镜时长与画幅属于创作文档；生成服务仅接受其协议支持的参数。当前视频编译使用 4/8/12 秒之一，其他分镜时长回退为 4 秒；竖屏使用 720×1280，其他画幅使用 1280×720。图片参数依所选模型尺寸规则适配，可能转换为 3:2、2:3 或 1:1，不能保证与创作画幅精确一致。请在画布任务参数中核对实际请求。

参考图编辑与首帧视频需要真实服务，不支持 DEMO。可提交的参考素材为 PNG/JPEG/WebP base64 图片；DEMO SVG 不能充当真实参考图。导入素材、生成图片和导演舞台 PNG 截图都可作为后续参考来源。参考图会发送给用户选择的供应商。

## 三维导演舞台

从导演节点或底部 3D 导演台入口打开。舞台使用真实 WebGL1 深度测试和着色几何，包含基础人形、方盒、球体、平面和可选地面网格。人物是预演用基础人形，不是生成角色模型。

左键拖动环绕摄影机，滚轮调整距离；使用正面、侧面、俯拍、透视预设，或编辑方位、仰角、距离、注视目标和视野角。通过物件列表选择对象，编辑名称、位置、旋转和缩放；支持增加与删除物件。当前没有画面点选、拖动变换 gizmo、骨骼动画或阴影。

“保存舞台”只保存场景文档；“截图并保存到画布”读取真实 WebGL canvas 像素，新增 PNG 素材节点并保存舞台。截图不包含选择高亮或界面控件，地面网格按开关状态保留。截图分辨率随当前视口及设备像素比变化，像素比上限为 2；不是任意指定分辨率离线渲染。Ctrl / ⌘ S 保存，关闭脏草稿需要确认。

支持可选等距柱状全景背景，来自场景关联节点或输入图片。图像必须可读取并满足浏览器 CORS 与 GPU 纹理尺寸限制。全景只提供环境背景，不从图片重建三维物体、深度或镜头运动。WebGL 不可用或上下文丢失会明确报错。舞台不渲染 MP4。

## 模型服务与凭据

设置包含通用、模型服务、默认模型与关于。手填多个提供商的实际服务地址、协议、模型 ID 和角色；文本、图片、视频、音频可分别设置默认模型，节点可继承默认或明确指定目录模型。Ollama 仅支持文本。模型角色和 metadata 候选是配置声明，不是在线能力认证。

凭据只在 Windows 原生密码框输入。网页没有密钥输入框和读回接口；项目只保存模型引用，不保存提供商目录或凭据。C# 使用 DPAPI CurrentUser 加密单文档，并以 revision/CAS 和跨进程锁提交。改地址、协议或认证需求会解除原凭据绑定。跨 Windows 账户不迁移，需要重新配置。新运行没有环境变量凭据回退。

“拉取模型列表”只读取已保存提供商的 OpenAI GET /models 或 Ollama GET /api/tags metadata；不下载权重、不认证余额或生成能力，也不自动推断图片/视频角色。目录为空时可明确使用 DEMO；引用、角色或凭据缺失时真实运行应明确失败。运行开始固定设置快照。

## 服务协议与边界

| 能力 | 当前实现 | 限制 |
| --- | --- | --- |
| 文本与模型分镜草案 | OpenAI /chat/completions；Ollama /api/chat | 非流式文本；模型草案需有效 JSON 并经显式应用 |
| 图片生成 | OpenAI 兼容 /images/generations | 模型尺寸与参数受白名单约束 |
| 参考图编辑 | multipart /images/edits，image 字段 | PNG/JPEG/WebP；服务必须支持该协议；无蒙版编辑界面 |
| 参考图视频 | multipart /videos，input_reference；轮询并下载 MP4 | 特定 OpenAI 兼容任务协议，不适配任意厂商私有协议 |
| 语音 | /audio/speech，WAV | 不是音乐、声音克隆或转录 |
| 本地三维 | WebGL1 场景文档与 PNG 截图 | 无图片重建、动画时间线、gizmo 或本地 MP4 导出 |
| 旧方案/EDL 节点 | 文本结构化方案，rendered:false、mediaUnderstanding:false | 不观看或理解上传视频，不自动剪辑成片 |

真实付费供应商/Ollama 在线认证与实际生成尚未完成本轮验收。协议实现和受控测试不能代替真实服务验收。不包含原站账号、会员、积分、云资产、协作、超分、转录或智能剪辑 MP4。

执行按 DAG 串行；错误停止后续任务，已产生结果保留。节点总时限 120 秒，提示词聚合上限 2 MiB。取消只停止本地请求和等待，不能撤回远端任务或计费。
