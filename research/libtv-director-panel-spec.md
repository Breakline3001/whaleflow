## 0. 一句话结论

**这是一个铺满整个窗口（1280×665）的全屏遮罩层**，遮罩底色 `rgba(8,8,16,0.98)`（近黑带蓝调），其内部是一个**全窗口 WebGL 画布**（3D 场景，1280×665，被两侧面板压住），上面浮着四组 UI：

## 6. 3D 视口（R2）

### 6.1 画布层

- 【DOM】`div.absolute.inset-0[role=presentation]` → `div.h-full.w-full` → `<canvas>` **rect 0,0,1280,665**，computed bg 透明、无圆角。
- 即：**3D 内容铺满整个窗口**，左右两侧的 281px 面板是"压在画面上"的，而不是把画布挤窄。复现时若把画布裁成 718 宽，页脚/场景透视会明显不同。
- 遮罩 `rgba(8,8,16,0.98)` 之下，底层 React Flow 的点阵背景（`#3C3C3C` 16px 网格）**完全不可见**——不要画点阵。

## 11. 数据缺口与陷阱（复现时必读）

| 陷阱 | 现象 | 处置 |
| --- | --- | --- |
| **depth 截断** | `位置/旋转/缩放` 的 3 列格、`统一缩放` 滑块、`颜色` 行在 JSON 里都是**空的容器** | 不要据"导出为空"判定界面没有子控件；按 §7.3 的像素反推补齐 |
| **`text` 为空但有字** | 搜索框「请输入搜索内容」、底部「描述想搭建的场景」都是 `placeholder` 属性，JSON `text` 为 `""` | 占位符文案从截图取，颜色按像素反算 |
| **`filter` 字段被复用** | JSON 的 `style.filter` 在 inspector 内层和底部胶囊上记的是 `blur(16px)/blur(24px)` | 这是 `backdrop-filter`，不是 `filter`；`filter` 若真生效会把整块内容糊掉 |
| **SVG 无几何** | 只有 `svg`/`path` 的 rect，没有 `d` | 图标只能按语义重绘，尺寸照 rect（16/20/14/24 四档） |
| **两态文字色相同** | 导演视角/机位视角 computed `color` 都是 `#F7F7F7` | 只切换背景，别把未选中态做成灰字（Tab 才是灰字 `white/45`） |
| **两个 header 高度不同** | aside 52，inspector 48 | 混用会左右错位 4px |
| **1px 边框归属** | 281 = 280 + 1px 边框 | 用 `width:281 + border` 会变 282 |
| **画布是全窗口的** | 3D 画面不是 718 宽 | 裁剪画布会让透视/构图跑偏 |
| **底部浮层的 68 高含 pb-5** | 外层 68，实际胶囊只占 597–645 | 用 68 减去 20 的 padding-bottom 做垂直对齐 |

## 12. 可复用测量 TOP-10（跨面板通用）

1. **侧栏宽度 281（含 1px 边框，内容盒 280）**：左右两侧完全对称，1280−281×2 = **718** 可视区。
2. **行/控件基准高 28px + 圆角 8px**：输入框、Tab、三轴格、数值框、图标按钮（32）全部落在 28/32 两档上，radius 只有 8/10/12/9999 四档。
3. **两种"白刷"填充**：`white/8` = 弱填充（搜索框、选中行、发送钮），`white/10` = 强填充（输入框、Tab 选中、模式开关选中、导航轨选中）。on `#171717` → `#292929`；on `#212121` → `#373838`。
4. **文字灰阶四档**：`white/85`（列表头/图标）、`white/75`（次行）、`white/45`（标签/未选中 Tab）、`white/28`（禁用）。`13px/white/45` 就是属性行标签的标准写法。
5. **属性行节奏 = 28(标签) + 4(mb-1) + 28(控件) = 60，块间距 12**：可直接公式化生成任意行数的 inspector。
6. **三轴输入 = `grid-cols-3` + `gap 4`**：248 宽三列 → 每格 **80×28**；格内 = 8px 内边距 + 16px 轴字母槽（`white/45`，12px）+ 左对齐数值（白 12px）。
7. **滑块复合控件口径**：轨道 170×4 + 间距 8 + 数值框 70×28 = 248；已填充 `#09CAF5`、未填充 `#5C5C5C`、拇指 10×10 白 —— 是全站唯一出现青色强调的位置。
8. **胶囊浮层规范**：高 **48**，`radius 9999`，底色 `rgba(33,33,33,.94)` + `backdrop-filter: blur(24px)` + `1px white/10`，内边距 8、间距 8；工具条 **128** = 3×32 + 4×8；输入条 **224**。
9. **模式开关三段式口径**：外 170×36/r12/pad2/gap2/#212121/1px `white/8`，内按钮 81×32/r10/13px/`0 8px`，选中只加 `white/10` 底；容器 `pointer-events:none`、内层包裹 `pointer-events-auto`。
10. **浮层定位习惯**：顶部居中（`left-1/2 -translate-x-1/2`, `top:8`）、底部居中（`inset-x-0 bottom-0` + `flex-col items-center`, 高 68 含 `pb-5`）、右侧 gizmo（72×72 圆 + 21 高按钮，距右栏 20、距顶 16）——全部以**窗口**为基准，不是以可视区为基准。
