**换算规则（全篇通用）**

```
截图设备像素 = canvas 逻辑尺寸 × zoom × dpr(2)
screen CSS px = 截图设备像素 ÷ 2
canvas 逻辑尺寸 = screen CSS px ÷ zoom
```

`node-layout.json` 里的 `cssWidth/cssHeight` 是 **canvas 逻辑尺寸**，`rect.w/h` 是 **screen 尺寸**。已交叉验证：`622 × 1.14151 = 710.02`（rect.w 实测 710.0187 ✔）、`350 × 1.14151 = 399.53`（rect.h 实测 399.5283 ✔），像素实测卡片外框 776..2194 = 709 CSS ✔。

## 2. 节点卡片解剖

### 2.1 外框与尺寸

| 节点类型 | canvas 宽 | canvas 高 | 圆角 | 边框 | 正文底 | 判据 |
| --- | --- | --- | --- | --- | --- | --- |
| 文本 `react-flow__node-text` | **350** | **200** | 12 | 1px `#525252` / 选中 `#A8A8A8` | `#171717` 或 `#262626`（见 2.8） | 【直读】`node-layout.json` cssWidth/Height；【实测】13 号 603.5 CSS ÷1.7288 = 349；15 号 398.5 CSS ÷1.14151 = 349 |
| 图片 `react-flow__node-image` | **622** | **350** | 12 | 1px（仅采样到选中态 `#A8A8A8`） | `#262626` | 【直读】同上；【实测】709.5 CSS ÷1.14151 = 621.5；399.5 ÷1.14151 = 349.9 |

- DOM 实况：`react-flow__node` 自身 `background: rgba(0,0,0,0)`、`border: 0`、`radius: 0`（`node-layout.json`）。**视觉内层卡片才是上表那些值**，抓取时内层 DOM 未被递归导出（children 只有一层空 div），所以卡片视觉必须从像素反推。
- 盒子模型判定为 `border-box`（边框画在 622/350 之内）：选中态光边框外沿正好落在 710 CSS 处。
- `selected` 类出现在 `className` 里（`node-layout.json` 图片节点 `… nopan selected selectable draggable`），文本节点没有 → 与边框亮/暗两态一一对应。

### 2.2 标题（caption）——**这个最容易被抄错**

| 项 | 值 | 判据 |
| --- | --- | --- |
| 字号/行高 | **13px / 20.15px**，`font-weight 400` | 【直读】01/10/11/13/15/16 全部一致 |
| 颜色 | `rgb(145,145,145)` | 【直读】 |
| 位置 | 卡片**上方、卡片外**，图标左缘与卡片左边缘对齐；文字起点 = 卡片左 + **18px** | 【实测】15 号：文字 x=406，卡片左 388 → +18；13 号：355 vs 337.5 → +17.5 |
| 与卡片顶的间隙 | caption 盒底边到卡片顶 ≈ **6.5px @114%**、**9px @173%** | 【实测】15：标签 y=210 h=20 → 底 230，卡顶 236.5；13：底 21，卡顶 30 |
| 前导图标 | 约 14×14，色 `#919191`；图片节点=图片图标、文本节点=文本/段落图标；图标与文字间距 ≈4 | 【实测】caption 放大裁切（15 号：图标 388–402、文字从 406 起） |
| 缩放行为 | **字号不随画布缩放**（counter-scale），但随节点走 | 【实测】同一个「图片节点 2」在 13(173%) 与 15(114%) 都是 w=64 h=20 |
| 文本格式 | `图片节点 N` / `文本节点 N`（N 为创建序号，从 1 起） | 【直读】13/15「图片节点 2」、10/11/12/13/15「文本节点 1」 |

复刻公式（【推测】，与三处实测吻合）：

```
caption 容器 = position:absolute; left:0; bottom: calc(100% + 5px);   /* 5 为 canvas 单位 */
caption 文本 = transform: scale(1/zoom);  transform-origin: left bottom;
             font: 400 13px/20.15px 同一字体栈; color: #919191;
```
> 为什么不是固定 6.5px：6.5/1.14151 = 5.7，9/1.7288 = 5.2，两者都收敛到「canvas 内约 5px」；而 18px 的左偏移在两个缩放下都是 17.5/18（**不缩放**）——这两条必须分别处理，否则放大后会明显错位。
