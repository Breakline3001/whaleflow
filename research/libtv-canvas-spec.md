# LibTV `/canvas` 画布 chrome 复刻规格（v2 基线 · 1280×665 @dpr2）

写给人看的实现规格：不看原站也能把外壳搭出来。
对象是 `https://www.liblib.tv/canvas` 的**画布外壳（chrome）**——顶栏、底部工具条、浮动面板、菜单、快捷键帮助。不含节点内部、连线几何、生成流程。

## 0. 判读规则与证据分级

本文件只依据三份离线材料：
[baseline-ui 采集](<D:/XYP/libtv-research/v2/baseline-ui.json>)（真实 DOM 的 `getBoundingClientRect` + `getComputedStyle`，2026-10-18T20:59:54Z，视口 1280×665 / dpr2，路由 `/canvas`）、
[六张截图](<D:/XYP/libtv-research/v2/screens/>)、
[字面线索清单](<D:/XYP/libtv-research/v2/STATIC-INVENTORY.md>)。

每条数字都带证据级标：

| 标 | 含义 | 可信度 |
| --- | --- | --- |
| **A** | DOM 采集值（rect / computed style），逐字来自 JSON | 最高 |
| **B** | 对 PNG 做像素采样得到（我本次离线量的，原图 2560×1330 = 2× CSS） | 高（±1px / ±1 色阶） |
| **C** | 肉眼看截图读出（形状、相对位置、文字） | 中，属**推测** |
| **D** | 静态字面量（只证明"文案存在"，不证明布局） | 中 |

**没有 A/B 标的数字一律按推测对待**，第 16 节汇总。
原站图标资源**没有**取到，也不许复制：所有图标只能重绘或替换（见第 14 节）。

> 同目录另有 [节点与菜单规格](./libtv-node-menu-spec.md)，覆盖节点卡片内部与三个菜单的逐项几何。本文职责是**画布外壳**（顶栏 / 底栏 / 工具簇 / 空态 / 图标）。两份在菜单章节有重叠，**同一字段若数值打架，以证据级高（A>B>C）的一方为准**。

### 1.1 画布点阵背景（可直接抄）

- 点：**1×1 CSS px**（dpr2 下 2×2 物理像素）
- 点色：`#3C3C3C`（`rgb(60,60,60)`）
- 步长：**16px × 16px**
- 相位：点位于 `x = 8 + 16k`、`y = 8 + 16k`（即容器左上角外 8px 起，第一颗点在 (8,8)）
- 全部为 B：在 `y=360/376/392...` 与 `x=8/24/40...` 上逐行逐列命中，间距恒为 32 物理px

等价的 CSS：

```css
.canvas {
  background-color: #141414;
  background-image: radial-gradient(circle, #3C3C3C 0.5px, transparent 0.5px);
  background-size: 16px 16px;
  background-position: 8px 8px;
}
```

（`radial-gradient` 半径 0.5px 在 dpr2 下正好落到 1px 点；若渲染偏差，用 `1px` + `background-size:16px` 也可接受。）

## 18. 证据与限制

- 只做了离线读取：`baseline-ui.json`（31KB 全读）、6 张 PNG（用图像输入看 + 用像素采样量）、`STATIC-INVENTORY.md`（全读）。
- **没有**联网、**没有**访问原站、**没有**读浏览器 profile / Cookie / IndexedDB（`libtv-research/v2/browser-private-*` 目录虽存在，本次未触碰）。
- 未复制任何原站图片/图标进仓库；本文所有颜色与尺寸都是采集值与测量值。
- 一次截图 = 一个状态。所有 hover / 打开态结论都只有 1–2 个样本，跨版本可能漂移。
- 采集序列是**叠加**的：`00-baseline` 是唯一干净态；`01..05` 里快捷键浮层一直开着，`02` 里还叠着添加菜单，`05` 里再叠一层画布列表。所以"某元素在 03/04 里带底色"要先排除它只是 hover 或被浮层压暗，本文已按此逐条标注。
- 像素测量基于 dpr2 原图，误差 ±1px / ±1 色阶；文字颜色一律取 computed 值，不从抗锯齿像素反推。
- 浮层不透明度是靠**同一坐标在 03 与 04 两张图上的差值**判定出来的（03 = 浮层压着菜单、04 = 浮层独处）：这是本次唯一"用两张图做 A/B"推出的结论，其余（#262626 菜单不透明）靠"浮层压在白色卡片文字上零透光"反证。
