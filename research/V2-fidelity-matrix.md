用户选择**独立本地版 + 自有 API/Ollama**，不选择原站网页 wrapper。参考的是已授权查看的登录后画布可见布局/操作；没有恢复网站完整源码、后端、账户系统或付费能力。**0.2.0核心对齐评审版已验收，不称“原站所有能力复刻完成”。**

## 模型、媒体与创作能力

| 能力/入口 | 本版真实执行语义 | 状态 / 不可冒称 |
| --- | --- | --- |
| 手写文本/便签 | 本地文字传递，不需要模型 | 源码实现；不是AI生成 |
| AI文字 | OpenAI兼容非流式 `/chat/completions` 或 Ollama `/api/chat` | 协议测试；未实测在线服务 |
| 文字生图 | `/images/generations`，返回base64/URL，经Node下载并嵌入 | 协议测试；非所有供应商/参数认证 |
| 图片参数 | 尺寸/比例/1–4张；已知GPT Image、DALL-E限制在UI提示/禁用不支持项，保存值不静默篡改 | 接口支持与UI约束，不是在线模型支持证据；[节点](<../src/CanvasNode.jsx>) / [参数](<../lib/generation-options.mjs>) |
| 图生图/图像编辑 | 同名入口导入/替换素材；带mediaUrl的图片节点透传，不执行编辑API | **未接入** `/images/edits` 等图像编辑能力 |
| 图片反推提示词 | 提示未接入视觉理解并提供素材导入 | **未接入**；上游图片只存在性说明，不把导入当反推 |
| 图片高清/超分 | 提示未接入高清接口，可调整新生成尺寸 | **未接入**；不把改尺寸当已有图超分 |
| 音频导入 | MP3/WAV/OGG/M4A/FLAC，签名与容量检查，原生返回单对象 | 后端测试，真实文件选择器/播放待验收 |
| TTS | `/audio/speech`，voice/input/model，WAV返回 | 协议测试；未实测真实服务，不含克隆/转录 |
| 文字生音乐 | 可连接音频节点，但提示仅TTS；DEMO仅测试音 | **音乐生成未接入**，不能把TTS/测试音称为音乐模型 |
| 视频导入 | MP4/WebM/MOV/OGV自包含媒体透传 | 源码实现；编码播放仍由WebView2决定 |
| 文字/参考图生视频 | OpenAI兼容multipart `/videos`→任务轮询→content；最后上游PNG/JPEG/WebP可作参考 | 协议测试，真实服务待验收；不是所有模型/首尾帧协议 |
| director 导演 | 根据文字/素材引用给出结构化创作方案 | **部分**；不含原站专有Agent/付费流程 |
| script 脚本 | 文本模型给出校验后的标题与条目 | **部分**；不是原站全脚本生产与同步系统 |
| shots 逐帧拉片 | 根据文字/素材引用给出镜头方案 | **部分**；没有抽帧、看视频、听音频或视觉理解 |
| clip 智能剪辑 | 输出description/sourceId及递增startSeconds/endSeconds建议 | **部分**；EDL计划，**MP4渲染未接入**，不是自动识别素材并剪出成片 |
| DEMO | 本地确定性文字、SVG、WAV测试音和结构化方案，明确demo标记；视频不伪造 | 离线演示，不声称AI生成/真实TTS |

所有方案输出声明 `rendered: false`、`mediaUnderstanding: false`。底层执行见[工作流引擎](<../lib/workflow.mjs>)。未读取、复制或调用原站付费 API，也未使用原站会员/积分为本地能力背书。
